# LEND
Peer-to-peer rental marketplace for Azerbaijan

## Run locally

```bash
npm install
npm run dev      # dev server at http://localhost:5173
npm run build    # single self-contained file at dist/index.html
```

The whole app lives in `src/App.tsx` and runs on sample data (no backend yet).
